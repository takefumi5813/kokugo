# 四字熟語の出題整理（2026-10-13）

全文回答114問、穴埋め168問、二つの熟語をつなぐ5問を、108熟語の穴埋め108問に統合した。四字熟語全体は466問から287問、全問題は13,095問から12,916問になった。意味・読み・用法・誤字訂正などの別目的の問題は変更していない。

- 穴埋めの解答は空欄の漢字のみ。全文回答しかなかった熟語も出題範囲を維持する。
- 統合した元問題の授業範囲、道場テスト印、注意記録は残す。
- 残す問題のIDを維持し、統合する旧IDを `mergedIds` に記録する。全対応は `yoji-consolidation.json` に保存。
- 起動時と旧バックアップ読み込み時に、最大の☆数を引き継ぐ。同じ☆数なら次の出題予定が遅い方の記録を採用する。移行時に新たな待ち時間は設定しない。
- 移行済みの旧IDは保存記録から取り除く。これにより、統合後の正誤判定や取り消しを再起動時に古い記録で上書きしない。
- ポイント、仲間、学習ログの保存形式は変更しない。バックアップ読み込みで現在の☆数を下げない。

検証：`node tests/yoji-consolidation.cjs`。元287問すべてのIDからの進捗継承、授業範囲、無関係な問題の保持、最大ランク・同ランク時の出題予定、起動時保存、再実行、旧バックアップ読み込みを確認する。

実ブラウザーでも旧IDの☆1・☆3を投入し、統合問題が☆3で表示され、正解後の☆4が再読み込み後も保持されることを確認済み。
