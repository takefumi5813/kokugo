# 漢字の読み問題の送りがな修正（2026-10-14）

Notion（国語DB）から取り込んだ読み問題のうち、台帳の「語(読みの部分)」形式の読みの部分だけが答えになり、送りがなが落ちていた問題を直した。例：「傷」→「いた」は「傷む」→「いたむ」に。「傷」1字なら読みは「きず」になるため、訓読みを問う問題には送りがなを付ける。

- 書き直し29問：問題と答えを語全体の形にした。IDは据え置きなので☆はそのまま。
- 統合11問：正しい形の同じ問題がすでにあるもの（「説く→と」と「説く→とく」など）や、1字の音読みだけで語にならないもの（「喜→き」「候→こう」「然→ぜん」）は、正しい問題に統合した。旧IDは残す問題の `mergedIds` に入れ、起動時に☆の高い方を引き継ぐ（四字熟語の統合と同じ仕組み）。
- 全対応は `reading-okurigana-fix.json`。

検出の基準：問題の末尾の送りがなが答えの末尾にない／問題中のかなが答えにない／答えのかなが漢字の数より少ない／答えに括弧が入っている。修正後はこの基準に当たる問題は0問。
